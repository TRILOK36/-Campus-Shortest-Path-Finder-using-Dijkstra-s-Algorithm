How the algorithm works

The campus is a weighted graph. Each building is a node, each walkway is an edge, and the edge weight is its length in metres. Dijkstra's algorithm works on graphs where no weight is negative.

  1. Set the distance of the start node to 0 and every other node to infinity.
  2. Pick the unsettled node with the smallest known distance. Call it u and mark it settled.
  3. For every neighbour v of u, check whether dist[u] + w(u,v) beats dist[v]. If it does, update dist[v] and remember u as its predecessor.
  4. Repeat from step 2 until the destination is settled. Follow the predecessors backwards to read off the route.

Think of it as ripples from a stone dropped at the start: the ripple always reaches nearer buildings first, so the first time it touches the destination is by the shortest route.

Complexity

With a binary min-heap, the running time is O((V + E) log V) and the memory is O(V). This model has 10 buildings and 16 walkways, so the result is instant. The same code scales to a full campus with hundreds of nodes.

Where it can be used

Campus navigation kiosks and mobile apps, visitor guidance, emergency evacuation routing, and any map where the cheapest route matters, such as road networks and network packet routing.
