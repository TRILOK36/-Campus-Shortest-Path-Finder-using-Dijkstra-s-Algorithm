# Campus Shortest Path Finder using Dijkstra's Algorithm

Sandip University, SOCSE, B.Tech CSE (AI & ML). Guide: Darshan Ahire.

## Files
- `dijkstra.py` – campus graph and Dijkstra's algorithm (heapq). Run: `python dijkstra.py`
- `generate_figure_and_trace.py` – draws `campus_graph.png` and prints the step trace (needs `pip install matplotlib`)
- `website/index.html` – interactive website, open directly in a browser (no install)
- `build_report.js` – script that generated the Word report (needs `npm install docx`, plus the logo and figure files; optional)
- **Live site**: https://path-finder-six-gold.vercel.app/
## Change the map
Edit `CAMPUS` in `dijkstra.py` (and `N`, `E` in `website/index.html`) with your real buildings and distances.
